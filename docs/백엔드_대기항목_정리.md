## 3. 회의에 올릴 우선순위

1. **Q3 · Q6** — 각각 관리자 결정 학습 루프, OCR 미리보기라는 기능 하나씩을 통째로 막고 있고 공수도 가장 크다(합 1.5~2.25일). 스펙 회신이 먼저다.
2. **C2 · C3(잔여) · R2** — 심사 코어 인터페이스 마무리. 개별 공수는 작지만(합 1일) 파일 여러 곳에 걸쳐 있다.
3. **R1(내부 API 응답 필드)** — claim 미포함이 확정된 만큼, 그에 따라 필요해진 지출 상세 조회 API의 실제 스펙(응답 필드)이 아직 없다.
4. **R6(API-043)** — 정책 추천 계약. 데모엔 영향 없으나 제안이 나간 지 오래됐다.

**전부 데모(Day 6) 필수 경로가 아니다** — 데모는 A-1~A-9·B-1~B-8만으로 이미 완결되어 있다
(`업무분장_스프린트1_작업명세_v2.md` §2.5: "Day 6 데모 일정은 조건부 트랙에 의존하지 않는다").
