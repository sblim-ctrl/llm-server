## 30초 요약

**심사는 비동기입니다.** 요청은 접수만 하고 202로 즉시 응답하며, 결과는 나중에 저희가
콜백으로 보냅니다.

```
[백엔드]  POST /v1/analyze          ──►  [LLM 서버]   접수 후 202 즉시 응답
[백엔드]  POST /agent-callback      ◄──  [LLM 서버]   심사 완료 시 결과 발신
                                                     ★ 이 수신 엔드포인트가 필요합니다
[백엔드]  GET  /v1/jobs/{job_id}    ──►  [LLM 서버]   폴링 fallback (콜백 유실 대비)
```

**모든 요청에 인증이 필요합니다** — `Authorization: Bearer <SERVICE_TOKEN>`
(면제는 `/healthz` · `/readyz` · `/docs` · `/redoc` · `/openapi.json` · `/ui` 6개뿐 —
문서 1번 §1 참조)

**저희도 백엔드를 호출합니다.** 심사 요청에는 `jobId`·`expenseId`·`organizationId` 등
5필드만 담으시면 되고, 지출 상세·예산·회칙은 저희가 내부 API로 되물어 가져옵니다(pull 모델).
→ 그래서 **문서 3번의 API가 없으면 심사가 시작되지 않습니다.** 가장 급한 항목입니다.

|---|---|

**전부 데모 일정에는 영향 없는 항목**이니 편하신 시점에 답 주시면 됩니다.
