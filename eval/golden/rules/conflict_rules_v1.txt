# 회칙 충돌 조항 세트 (golden_v2 rule_conflict 유형 전용)
#
# 실모드 전용 자료다 — 목 모드 rule_auditor는 회칙 미인덱싱 팀에 대해 항상 기본 정책
# 모드(no_rules)로 빠져 verdict="pass" 고정값만 내므로, 아래 충돌 조항이 인덱싱되어도
# 목 모드에서는 아무 효과가 없다(scripts/golden_v2/engine.py 모듈독스트링 참조). 실모드
# run_eval_v2_real.py가 이 파일의 각 섹션을 rule_conflict 유형 조직의 회칙 본문에
# app/tools/backend_client.py get_policy_document()의 표준 11개조 뒤에 덧붙여 인덱싱한다
# (eval/fixtures/mock_backend.json의 "policy_documents"[team_id] 오버라이드로 연결).
#
# 각 섹션은 "## 충돌:" 로 시작하고, 표준 제2조(1인당 회식비 3만원 한도)와 서로 다른
# 방향으로 부딪히는 특별 조항 하나를 담는다. rule_auditor(실 LLM)가 일반 조항과
# 특별 조항 중 무엇을 근거로 삼는지, 어느 쪽이 "더 구체적인 규정"으로 우선하는지를
# 관찰하는 것이 이 유형의 목적이다 — 정답은 코드로 유도할 수 없어 케이스마다 손으로
# 판단해 golden_v2/rule_conflict.json에 적었다(§4.5 예산 우선순위와는 별개 축).

## 충돌: 송년회 특별 한도 (금액 상향)
제12조 (송년회 특별 조항) 연말 송년회 회식비는 참석 인원 1인당 5만원까지 인정한다.
이는 제2조의 통상 회식비 한도(3만원)에 대한 예외로, 12월 중 개최되는 공식 송년 행사에
한해 적용한다.

## 충돌: 신입 회원 환영회 한도 (금액 하향 + 조건부)
제13조 (신입 회원 환영회 조항) 신입 회원 환영을 목적으로 하는 식사 모임은 예산 절감을
위해 1인당 2만원을 넘을 수 없다. 이는 제2조의 통상 회식비 한도(3만원)보다 낮은 금액으로,
환영회 성격의 지출에 우선 적용한다.

## 충돌: 전체 총회 회식 한도 (금액 상향 + 다른 근거)
제14조 (전체 총회 조항) 연 1회 개최하는 전체 총회 직후 회식은 총회 참석을 독려하기
위해 1인당 4만 5천원까지 인정하며, 총무는 총회 참석자 명부로 인원을 확인한다. 제2조의
통상 회식비 한도(3만원)와 달리 이 조항은 총회 당일 회식에만 적용한다.
